# История версий

## 0.1.0

- Первый релиз плагина `opencode.proxy-router`.
- Локальный reverse-proxy на `127.0.0.1`: URL вида `/<upstream-host>/<path>`, стриминг без буфера.
- Внешние прокси: HTTP/HTTPS через `CONNECT`, SOCKS5/SOCKS5h (RFC 1928 + RFC 1929).
- Подмена `settings.baseURL` через `ctx.model.transform` — включение и выключение на лету,
  без перезапуска сервиса.
- Команда `/proxy on|off|status` и инструмент `proxy_router`.
- Allowlist хостов: релей ходит только на хосты, которые встретились в baseURL перенаправленных
  моделей; остальные запросы получают `403`.
- Пароль прокси маскируется в логах и в статусе; заголовки авторизации не логируются.
- Поддержка `upstreams` для провайдеров без `settings.baseURL`.
- Тесты на `node --test` с фейковыми апстримом, HTTP-прокси и SOCKS5-прокси; ручной
  интеграционный тест через реальный прокси.
