# AGENTS.md — проект OpenCode_ProxyRouter

## Назначение

Плагин OpenCode V2, который поднимает локальный reverse-proxy на `127.0.0.1` и подменяет
`settings.baseURL` у выбранных моделей, чтобы их трафик шёл через внешний HTTP/SOCKS5-прокси.
Нужен для моделей с региональными ограничениями (Beam Free, Muse Spark Contributor).

Главная причина существования релея: в V2 запросы к провайдерам выполняет фоновый сервис, и
`HTTP_PROXY` из шелла до него не доходит. Model transform + baseURL применяются без рестарта.

## Структура

| Файл | Роль |
|---|---|
| `plugin/index.js` | Плагин: опции, `ctx.model.transform`, `/proxy`, инструмент `proxy_router`, жизненный цикл релея. |
| `plugin/relay.js` | HTTP-сервер релея, разбор `/<host>/<path>`, allowlist хостов, стриминг. |
| `plugin/dialer.js` | `parseProxy`, CONNECT (HTTP/HTTPS-прокси), SOCKS5/SOCKS5h, TLS-обёртка. |
| `tests/*.test.mjs` | `node --test`: фейковые апстрим и прокси, проверка протокола. |
| `tests/integration.mjs` | Ручной тест через реальный прокси (`PROXY_ROUTER_TEST_PROXY`). |
| `README.md` | Пользовательская документация. |
| `CHANGES.md` | История версий. |

## Правила кода

- ESM (`package.json` → `"type": "module"`), только `node:`-модули, без зависимостей.
- `plugin/index.js` экспортирует `{ id: "opencode.proxy-router", setup(ctx) }`, `setup` возвращает
  cleanup: закрыть релей и dispose всех регистраций.
- Transform-колбэк синхронный и идемпотентный: при каждом пересборе реестра он заново вычисляет
  baseURL из **исходного** `provider.settings.baseURL` / `model.settings.baseURL`, а не из прошлого
  результата.
- Ошибки конфигурации не должны ронять плагин: логируем, остаёмся загруженными, `/proxy status`
  показывает причину.
- Релей не логирует заголовки авторизации и пароль прокси (`redactProxy`).
- Релей принимает только хосты, которые плагин разрешил через `allowHost()`.

## Тонкости, которые легко сломать

- `http.request({ agent: false, createConnection })` **не использует** переданный сокет — клиент
  открывает своё соединение. Нужен отдельный `Agent` с переопределённым `createConnection`.
- `https.request` поверх уже готового TLS-сокета работает; `http.request` в той же схеме даёт
  странные ответы от Cloudflare (301), поэтому транспорт выбирается по `secure`.
- Тестовый хост `relay.invalid` не резолвится намеренно: тест доказывает, что соединение идёт
  через туннель, а не напрямую.
- `socks5://` резолвит имя локально (только IPv4), `socks5h://` отдаёт имя прокси.

## Тесты

```powershell
node --test
$env:PROXY_ROUTER_TEST_PROXY = "http://192.168.0.250:2081"
node tests/integration.mjs
```

Новые фичи протокола (новый тип прокси, заголовки, стриминг) должны покрываться тестом на
фейковом сервере, а не только проверкой «на глаз» в TUI.

## Чего не делать

- Не копировать плагин в `~/.config/opencode/plugins`: опции передаются только через `plugins`
  в `opencode.json`, а автообнаружение их не умеет.
- Не логировать `proxy` вместе с паролем и заголовки провайдера.
- Не добавлять в `models` модели с WebSocket-транспортом — релей их не проксирует.
